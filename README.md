# rundownmeetuplatsar

Web Rundown Kegiatan Main & Memory Vault Teman Latsar (Minggu, 27 September 2026).

## Fitur Utama
- **Countdown Interaktif**: Menghitung mundur otomatis menuju 27 September 2026 pukul 07:30 WIB.
- **Bola Foto 3D Interaktif (Sphere Image Grid)**: Pratinjau galeri foto 3D dinamis yang dapat digeser dan diputar dengan fisika momentum dan spotlight modal.
- **Aturan Dress Code Estetik**: Kombinasi warna Dark Brown & Warm Cream untuk 4 sahabat (2 cewe berjilbab & 2 cowo).
- **Rekomendasi Transportasi Umum Lengkap**: Disertai nomor koridor/rute spesifik untuk TransJakarta, JakLingko mikrotrans, KRL Commuter Line, serta MRT/LRT.
- **Kamera & Kompresi Otomatis**: Jepret foto langsung dari browser dengan kompresi instan hemat kuota.
- **Penyimpanan Ganda**: Tersimpan lokal secara offline di browser (IndexedDB) dan sinkronisasi otomatis ke Google Drive via Google Apps Script.
